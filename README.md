### Cấu hình kết nối cơ sở dữ liệu

Để kết nối với cơ sở dữ liệu `quanly_ban_sua`, cần tạo file `config.php` với các thông tin:

* `servername`: Tên máy chủ cơ sở dữ liệu
* `username`: Tên tài khoản MySQL
* `password`: Mật khẩu MySQL
* `dbname`: Tên cơ sở dữ liệu

> **Lưu ý:** File `config.php` không được đưa lên GitHub vì có chứa thông tin đăng nhập cơ sở dữ liệu.
